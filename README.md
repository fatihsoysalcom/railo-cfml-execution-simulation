# Railo CFML execution simulation

This Python script simulates the execution of basic ColdFusion Markup Language (CFML) code, mimicking how a Railo server might process different logic and data structures. It demonstrates core CFML concepts like variable assignment, conditional statements, loops, and data dumping through mock functions.

## Language

`python`

## How to Run

Run the script using Python: `python railo_test.py`
